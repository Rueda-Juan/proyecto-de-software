# Prompt para la ia

debes crear un sitio web estático responsivo(PC, tablet y celular) para promocionar destinos turísticos que dividido en 2 categorías:

- Playa
- Montaña

Usar únicamente HTML y CSS. (NO usar JavaScript ni frameworks)
Crear una barra de navegación con enlaces a:

- Inicio
- Playa
- Montaña
- Contacto
- Quién mantiene el sitio

Crear al menos 3 destinos por categoría:

- playa:
  - mar del plata
  - las toninas
  - santa teresita
- montaña:
  - tandil
  - san martin de los andes
  - humahuaca

Cada destino debe tener:

- Nombre
- Imagen
- Breve descripción
- boton para descargar su itinerario en PDF

Todo el CSS debe estar en un archivo separado llamado `estilo.css`, Las imágenes deben estar en `imagenes/` y ser `.png`, Los itinerarios deben estar en `guias/` y ser `.pdf`, Crear un formulario simple en `contacto.html`, y una página con información sobre quién mantiene el sitio.

## Estructura de archivos

- index.html
- playa.html
- montana.html
- contacto.html
- mantenedor.html
- estilo.css
- imagenes/
- guias/

## Consideraciones estéticas

- Mantener el código ordenado y sin sobreingeniería.
- Usar HTML semántico.
- Mantener el código simple.
- Preferir destinos turísticos argentinos.
